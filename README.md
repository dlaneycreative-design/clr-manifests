# CLR manifests

Machine readable manifests for the Clear libraries, published so partner tools can fetch them directly.

- clear-music-batches-1-6.json: every sound in CLR Music batches 1 to 6 (plus the 15 batch 4 soundboard gap fillers, 5,515 records) with source identifiers and SHA-256 checksums (file bytes and canonical decoded audio).
- HASH-RECIPE.md: the exact procedure for reproducing the pcm_sha256 content hash.
